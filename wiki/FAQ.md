# FAQ

## 忘了管理员密码怎么办？

账号保存在数据库 `harbor-dl.sqlite3` 里，目前没有找回密码的功能。最直接的办法是换一个全新的数据目录重新创建管理员，但订阅、任务和设置也会随之重置，操作前请先备份旧的数据目录。

## 拉取镜像提示没有权限

镜像包还是私有的，见 [[Quick Start]]。

## 点「登录抖音」后浏览器没有出现 / 崩溃

- Docker：确认 `shm_size: "1gb"`，并查看 `docker logs harbor-dl`；
- 本地：设置 `HARBOR_CHROME` 指向 Chrome / Chromium。

见 [[Browser Login]]。

## 订阅显示「需要重新登录」

抖音的登录状态过期了，到「添加订阅」弹窗或设置里重新登录并保存。

## 检查更新提示「可能还有更多新作品」

增量检查有页数上限（首次 3 页，之后 5 页）。做一次「全量同步」读取完整历史即可。

## 下载偶尔失败 / 返回空响应

抖音的接口依据公开的网页端行为实现，真实环境偶尔会返回 403 / 空响应（风控），请求会自动重试；降低「同时同步的订阅数」更不容易触发风控。平台改版也可能使其失效。

## 播放器提示「浏览器无法播放此格式」

浏览器只能播放自己支持的编码。点「保存文件」用本地播放器打开，或用手机 App。

## Jellyfin / Emby 里看不到导出的内容

- 确认已在「设置 → 媒体服务器」启用导出并点过「导出全部已下载作品」；
- Docker 下要把媒体库目录挂载出来，并让 Jellyfin / Emby 容器挂载同一路径；
- 媒体库类型选「电影」或「家庭视频」。

见 [[Media Server Export]]。

## 图集作品为什么没有导出 / NFO？

图集支持打包 ZIP 下载，也会导出到媒体库目录（图片按顺序编号 + 背景音乐），但 Jellyfin 没有「图集」类型，在其中的显示效果有限。

## 服务重启后下载任务怎么办？

未完成的下载会自动重新排队，最多 3 次，之后标为失败等待手动重试。

## 能直接放到公网吗？

不建议。放在带 TLS 的反向代理之后，见 [[Deployment and Backup]]。Cookie 目前明文保存在数据库里，请保护好数据目录。

## 我该只下载什么内容？

请遵守各平台的服务条款，只下载你有权保存的内容。
