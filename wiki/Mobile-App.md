# Mobile App

仓库的 `mobile/` 目录是一个 Flutter 编写的 **Android** 配套 App，定位是「自己媒体库的远程控制台」：由 App 发起，服务端执行。

> App 没有预构建发布包，需要自己构建并侧载安装（见下文）。当前版本在 `mobile/pubspec.yaml` 里。

## 功能

- **登录**：填写服务器地址 + 用户名密码，换取长效 token（365 天，可在网页「设置 → API Token」吊销）。登录失败限流与网页共用。
- **首页**：竖滑信息流，推荐 / 最新 / 收藏 / 历史四个标签；双击点赞、长按 2× 快进、可拖动进度条、自动连播 / 单曲循环、播放时屏幕常亮、小窗播放。
- **博主**：列表（搜索、三种排序）与详情（作品封面网格，点开从该视频起全屏播放）；包含已同步但未下载的作品，可请求下载。
- **订阅**：列表、检查更新、全量同步、下载全部或分批下载（最新 20 / 50 / 100）、按状态筛选、长按多选。
- **下载**：任务队列（进度、速度、取消 / 重试 / 删除），粘贴链接或分享文本 → 解析 → 选画质 → 下载。
- **直播**：订阅页右上角，检测是否开播、开始 / 停止录制、监控开关、录制记录。
- **图集**：已下载的图集可左右滑动看图并播放背景音乐。
- **我的**：更换头像与主页背景、收藏 / 历史、离线副本（无网浏览）、仅 Wi-Fi 预加载、缓存大小上限、服务器状态与日志。

仍只能在网页端做：登录平台（内嵌浏览器）、改密码、管理 API Token。

## 构建与安装

```bash
cd mobile
flutter analyze && flutter test
flutter build apk --release
```

- 每次发新包都要提高 `pubspec.yaml` 里的版本号（`version: x.y.z+N`），否则部分系统会静默忽略覆盖安装。
- 未配置 `mobile/android/key.properties` 时，release 包会用 debug 密钥签名；换成正式密钥后需要先卸载旧包。
- 后端要让手机访问：`uvicorn backend.app:app --host 0.0.0.0 --port 8765`，并放行防火墙入站 8765。Docker 部署已经监听 8765。

## 安全

目前只面向局域网：App 允许明文 HTTP。要上公网请放在带 TLS 的反向代理之后，并为 App 单独创建权限合适的 API Token。详见 [[Deployment and Backup]]。

更详细的现状与计划见仓库 `docs/mobile.md` 和 `docs/mobile-roadmap.md`。
