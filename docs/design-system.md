# Harbor-DL 设计规范

界面的基调是**港湾**：鼠尾草绿的底色、墨绿的主色、少量金色点缀（Logo 的 H 字标），克制、安静、以内容（封面、标题）为主角。所有字面量颜色、圆角、字号、间距只定义在 [`frontend/src/design/tokens.css`](../frontend/src/design/tokens.css)，组件只引用变量，不再写十六进制色值或零散的像素值。

## 规则

1. 新样式只用 `var(--…)`。需要的值不在表里，先改 `tokens.css`（亮、暗三处同步），不要在组件里写字面量。
2. 颜色按**角色**选，不按“长得像”选：正文用 `--text`，说明用 `--text-2`，元信息用 `--text-3`，`--text-4` 只给占位符和装饰图标。
3. 状态色成套使用（`-soft` 底 + `-text` 字 + `-border` 边），不要混搭。
4. 一个界面里同一角色只用一个圆角：控件 `--r-md`，卡片与面板 `--r-lg`，标签 `--r-sm`，圆形按钮用 `50%`，胶囊用 `--r-pill`。
5. 字号不小于 11px。间距走 4px 网格（2 和 6 为半步）。
6. 主题：`:root` 为浅色；`data-theme="dark"` 或系统深色偏好时覆盖同名变量。组件里不要写依赖某一种主题的颜色。

## 字体与字号

字体 `--font-sans`（Noto Sans SC 优先），Logo 字标用 `--font-display`。

| 变量 | 大小 | 用途 |
| --- | --- | --- |
| `--fs-11` | 11 | 标签、状态、元信息 |
| `--fs-12` | 12 | 次要文字、紧凑控件 |
| `--fs-13` | 13 | 控件与列表行的默认字号 |
| `--fs-14` | 14 | 正文 |
| `--fs-16` / `--fs-18` | 16 / 18 | 卡片、区块标题 |
| `--fs-20` / `--fs-24` | 20 / 24 | 小节标题、品牌 |
| `--fs-28` / `--fs-32` | 28 / 32 | 页面标题、关键数字 |

## 间距、圆角、阴影、动效

- 间距 `--sp-2 --sp-4 --sp-6 --sp-8 --sp-12 --sp-16 --sp-20 --sp-24 --sp-32 --sp-40 --sp-48 --sp-64`。组件内边距常用 8 / 12 / 16，区块间距 20 / 24 / 32。
- 圆角 `--r-sm` 4、`--r-md` 8、`--r-lg` 12、`--r-xl` 16、`--r-pill`。
- 阴影 `--shadow-sm`（悬浮的小件）、`--shadow-md`（卡片悬停、菜单）、`--shadow-lg`（对话框、播放器）。暗色下自动加深。
- 动效 `--dur-fast` 0.12s、`--dur` 0.2s，缓动 `--ease`。系统开启“减少动态效果”时全部动画收敛为瞬时。

## 布局与控件尺寸

- **页面宽度**：内容区最大宽度 `--page-max`（1280px），在侧栏右侧的剩余空间里居中，宽屏不再贴左。表单型页面（设置）在宽屏下排成两列，窄于 1100px 时单列。
- **控件高度只有三档**：`--control-sm` 30px（表格行内、分页）、`--control` 36px（默认，所有输入框、下拉框、按钮）、`--control-lg` 42px（首页的快速解析栏、登录与弹窗里的主表单）。同一行里的输入框和按钮必须同一档。
- **字号**：控件内文字统一 13px（小号 12px、大号 14px）。输入框、下拉框、按钮的圆角都是 `--r-md`。
- **按钮加尺寸用类**：`.sm`、`.lg`；输入框需要特殊高度用 `.field-sm`、`.field-lg`。不要在页面样式里给单个控件写 `padding` 和 `font-size` 来调大小。
- **交互状态**：悬停边框加深，聚焦为主色边框加 3px 淡绿光圈，禁用为灰底与 `not-allowed` 光标，按下下沉 1px，键盘聚焦显示 2px 轮廓（`:focus-visible`），出错的输入框设 `aria-invalid="true"` 即显示红边。

## 组件约定

- **主按钮**：`--brand` 底、`--on-brand` 字，悬停 `--brand-hover`；一个区域只放一个。
- **次按钮**：`--surface` 底、`--border-strong` 边；危险操作用 `--danger-text`。
- **输入框**：`--surface` 底、`--border-strong` 边、`--r-md`，聚焦用 `--focus` 的 2px 轮廓。
- **卡片 / 面板**：`--surface` 底、`--border` 边、`--r-lg`，不加阴影；悬浮层才用阴影。
- **状态标签**：`--r-sm`、11px，成套用状态色（如已完成 = `--success-soft` + `--success-text`）。
- **封面图**：本地缓存的封面（`/api/covers/…`）铺满 `object-fit:cover`，没有封面时显示格式与播放按钮占位。

## 本次迁移的说明

- 把原先约 60 种相近的灰绿色收敛为上表的角色色，10 种圆角收敛为 4 档，字号收敛为 10 档，内边距与间距就近吸附到 4px 网格。原先偏浅的元信息文字（对比度约 2.5:1）统一加深到 `--text-3`，整体观感略有变化。
- 订阅页原有的局部变量（`--ink`、`--line`、`--muted` 等）已并入这套变量，不再单独定义。
- 还没有统一的是各页面里并列存在的几套按钮与标签类（`.primary`、`.btn`、`.chip`、`.tag`、`.status`），它们现在共用同一套颜色和圆角，但结构还没合并，后续可以抽成公共组件。

## 播放器

- **快速预览**（播放弹窗）：[Plyr](https://github.com/sampotts/plyr) 封装在 `components/MediaPlayer.vue`，主题变量在 `design/plyr-theme.css`，只引用设计令牌，亮暗自动跟随。图标雪碧图 `design/plyr.svg` 随项目打包，不请求外部 CDN。底层仍是原生 `<video>/<audio>`，断点续播通过它的 `data-asset-id` / `data-subscription-id` 工作。字幕轨在列表返回后才创建播放器（Plyr 创建时读取 `<track>`）。
- **沉浸播放**：`player/ImmersivePlayer.vue`，全屏竖向 scroll-snap feed，只播放当前条、只挂载前后各一条（图集只在当前条挂载，避免多路音乐）。入口：媒体库筛选栏、订阅作品页工具栏、播放弹窗的"沉浸模式"。快捷键：↑/↓ 或 PageUp/PageDown 切条，空格暂停，←/→ 快退快进 5 秒，M 静音，Esc 退出。浏览器拒绝带声音自动播放时自动静音并给出提示。纯逻辑在 `player/feed.js`，有单元测试。
- 播放记录始终由 `App.vue` 统一保存，两种播放器共用同一套逻辑。
